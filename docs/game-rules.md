# Правила игры

## MVP

- 4–10 игроков, одна собственная карта;
- 1 предатель для 4–6 игроков, 2 для 7–10;
- лобби → игра → обсуждение → голосование → игра или завершение;
- 45 секунд обсуждения, 30 секунд голосования, 20 секунд cooldown убийства;
- экипаж побеждает по заданиям или после исключения всех предателей;
- предатели побеждают, когда их не меньше, чем живых членов экипажа.

## Серверные ограничения

- стартует только хост при допустимом составе;
- роль и персональные задания получает только их владелец;
- скорость, коллизии, дистанции и cooldown проверяет сервер;
- тело репортится один раз;
- живой игрок голосует один раз, мёртвый не голосует;
- при равенстве или большинстве Skip никто не исключается;
- после каждого важного действия проверяются условия победы;
- при выходе хоста в лобби хостом становится следующий игрок.

## Уже работает в Sprint 1

Создание/вход, уникальные имена в комнате, лимит 10, код из шести символов, передача хоста, границы карты, препятствия и серверно вычисляемое движение.

Роли, старт матча, задания, убийства, репорт, голосование и победа описаны как требования следующих Sprint и пока не реализованы.
