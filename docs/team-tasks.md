# Команда и Sprint 1

Цель Sprint 1: два игрока входят в одну комнату и видят перемещение друг друга на общей карте. Issues оставляются без assignee, пока не известны GitHub-логины участников.

| № | Роль | Задача Sprint 1 | Критерий приёмки |
|---:|---|---|---|
| 1 | Team Lead / Integration | Каркас monorepo, контракты, CI, интеграция | `check`, `test`, `build` проходят; две вкладки играют |
| 2 | Frontend — Home/Lobby | Улучшить Create/Join, состояния загрузки и ошибок | клавиатура и mobile layout, понятные ошибки |
| 3 | Frontend — Lobby/HUD | Ready, копирование кода, экран ожидания | список обновляется без перезагрузки |
| 4 | Game — Player | Prediction/interpolation и анимация персонажа | движение визуально плавное при задержке |
| 5 | Game — Map | Разнести карту/коллизии в модуль и добавить тестовую карту | клиент и сервер используют одну геометрию |
| 6 | Backend — Rooms | Ready, leave, host transfer, очистка комнат | unit-тесты lifecycle и лимитов |
| 7 | Realtime | Tick/snapshot, sequence, reconnect token | повторное соединение возвращает игрока |
| 8 | Gameplay — Tasks | Спецификация и mock одной задачи без merge в match | контракт согласован, прототип изолирован |
| 9 | Gameplay — Social | Спецификация state machine ролей/репорта/голосования | таблица фаз и серверных проверок |
| 10 | QA / DevOps | E2E smoke для двух клиентов, CI и test plan | воспроизводимый отчёт и список edge cases |

## Порядок интеграции

1. №1, №6 и №7 согласуют контракты.
2. №2–5 работают параллельно в своих папках.
3. №8–9 готовят следующий Sprint, не меняя публичные контракты без ревью.
4. №10 проверяет каждый интеграционный PR и хранит короткий smoke-сценарий.

## Ежедневный контроль Team Lead

- 10 минут: что сделано / что сегодня / блокер;
- убедиться, что у каждой Issue есть владелец и критерий приёмки;
- сначала ревью контрактов и серверной безопасности, затем UI;
- конфликтующие изменения развести до написания кода;
- в конце дня слить только зелёные PR и провести тест в двух вкладках;
- декоративные задачи снимать раньше, чем сетевую целостность.

## Definition of Done Sprint 1

- чистая установка по README;
- `/health` отвечает 200;
- две вкладки создают/входят в комнату;
- оба имени видны, движение синхронизируется;
- скорость и стены проверяются сервером;
- выход игрока обновляет состав, хост передаётся;
- CI выполняет typecheck, тесты и production build;
- известные ограничения записаны, секретов и чужих ассетов нет.
