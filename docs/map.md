# Карта «Орбитальная станция»

Владелец: №5 Game — Map. Одна геометрия для клиента и сервера.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `shared/src/map/station.ts` | Данные карты: комнаты, коридоры, мебель, точки заданий, места спавна. Стены и двери генерируются автоматически. `collides()` — проверка столкновения круга игрока. |
| `shared/src/index.ts` | `MAP` теперь = `STATION_MAP` (формат прежний: `width`, `height`, `playerRadius`, `speed`, `obstacles`). |
| `client/src/game/map/StationRenderer.ts` | Отрисовка в Phaser без внешних ассетов: звёзды с параллаксом, пол, стены с неоном, двери, мебель, свет, анимации, баннер комнаты. |
| `client/map-preview.html` | Превью карты со свободной камерой для разработки. |
| `server/src/rooms/StationMap.test.ts` | Тесты: спавн свободен, из станции нельзя выйти, все комнаты и задания досягаемы. |

## Как поменять карту

1. Правьте `ROOMS`, `CORRIDORS`, `PROPS`, `TASK_SPOTS` в `station.ts`. Коридор должен вплотную касаться двух комнат — двери появятся сами.
2. Проверьте: `npm test` (тесты карты) и `npm run dev` → http://localhost:5173/map-preview.html
   (`C` — коллизии, `T` — задания, `?zoom=0.4&x=1300&y=900` — позиция камеры).

## Для других ролей

- **№4 Player:** камера уже ограничена `MAP.width/height`; спавн — `MAP.spawnPoints`.
- **№6/№7 Backend/Realtime:** сервер использует `collides()` из shared — та же формула, что была.
- **№8 Tasks:** точки заданий — `MAP.taskSpots` (`wires` ×4, `fuel` ×3). Подсветить свои задания: `stationMap.highlightTasks(spots)`.
