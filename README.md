# Space Betrayal

Учебная браузерная 2D multiplayer-игра для 4–10 игроков по механикам Among Us. Матч проходит на одной карте «Орбитальная станция» с собственной графикой. Проект не связан с Innersloth.

## Быстрый локальный запуск

Нужны Node.js **20.19+** и npm **10+**. Выполните в корне репозитория:

```bash
npm install
npm run dev
```

- [Игра](http://localhost:5173)
- [Сервер](http://localhost:3001)
- [Проверка состояния сервера](http://localhost:3001/health)
- [Превью карты с коллизиями и заданиями](http://localhost:5173/map-preview.html?debug&tasks)

Команда запускает React/Vite-клиент и Express/Socket.IO-сервер. Для стандартного запуска файл окружения не нужен. При необходимости скопируйте `.env.example` в `.env` в корне и перезапустите процессы.

| Переменная | Стандартное значение |
| --- | --- |
| `PORT` | `3001` |
| `CLIENT_ORIGIN` | `http://localhost:5173` |
| `VITE_SERVER_URL` | `http://localhost:3001` |
| `MIN_PLAYERS` | `4` |
| `DISCUSSION_DURATION_MS` | `45000` |
| `VOTING_DURATION_MS` | `30000` |
| `KILL_COOLDOWN_MS` | `20000` |

Для быстрой проверки используйте `DISCUSSION_DURATION_MS=10000`, `VOTING_DURATION_MS=10000` и `KILL_COOLDOWN_MS=2500`. С `MIN_PLAYERS=2` удобно проверять лобби, роли и движение. Для сценария с убийством, репортом и голосованием оставьте четырёх игроков, чтобы первое убийство не завершило матч.

## Локальный матч

1. Откройте игру в четырёх вкладках. В первой введите имя и создайте комнату. Скопируйте код и войдите в комнату из трёх других вкладок с разными именами.
2. Нажмите **Ready** в гостевых вкладках, затем **Start** в первой. В каждой вкладке появится её секретная роль, затем загрузится карта.
3. Подвигайте одного игрока и проверьте его положение в другой вкладке. Мирным доступны личные задания **Wires** и **Fuel**, отмеченные на карте.
4. Выполните задание через **Use**. Проверьте, что командный прогресс обновился в других вкладках.
5. По окончании перезарядки предатель выбирает ближайшего мирного и нажимает **Kill**. Другой живой игрок подходит к телу и нажимает **Report**.
6. После обсуждения два живых мирных голосуют за предателя, а предатель может выбрать **Skip**. На экране результата появятся победитель, причина и роли всех участников.
7. Нажмите **Вернуться в лобби** или **Новый матч**, заново отметьте готовность и запустите второй раунд с тем же кодом комнаты.

### Управление

| Клавиши или кнопка | Действие |
| --- | --- |
| **WASD**, **стрелки** | Двигаться |
| **E**, **Use** | Открыть ближайшее назначенное задание |
| **Esc** | Закрыть задание |
| **Kill** | Устранить выбранного игрока рядом, доступно живому предателю |
| **Report** | Сообщить о теле рядом |
| **Голосовать**, **Skip** | Выбрать живого игрока или пропустить голосование |

## Правила и ограничения

- В матче с 4–6 игроками один предатель, с 7–10 игроками их два. Экипаж выигрывает, выполнив все задания или исключив всех предателей. Предатели выигрывают при численном равенстве с экипажем или перевесе.
- В голосовании исключается участник, набравший больше голосов, чем любой другой вариант. При победе Skip или ничьей никто не выбывает. Подробности в [правилах](docs/game-rules.md).
- Комнаты живут в памяти одного процесса. При обрыве соединения или обновлении страницы участник покидает комнату. Повторный вход по коду доступен в лобби.
- Игра рассчитана на управление с клавиатуры. В проекте одна карта, режим локальной игры по коду и нет встроенного чата.
- Vite предупреждает о размере общего чанка Phaser при production build.

```bash
npm test

git status
```
