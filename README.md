# Space Betrayal

Учебная браузерная 2D multiplayer-игра для 4–10 игроков по механикам Among Us. Хост выбирает одну из двух карт с собственной графикой. У экипажа семь типов авторских мини-заданий.

## Быстрый локальный запуск

Нужны Node.js **20.19+** и npm **10+**. Запустите из корня репозитория.

```bash
npm install
npm run dev
```

- [Игра](http://localhost:5173)
- [Проверка состояния сервера](http://localhost:3001/health)
- [Превью «Орбитальной станции»](http://localhost:5173/map-preview.html?map=station&tasks)
- [Превью «Глубинного маяка»](http://localhost:5173/map-preview.html?map=abyss&tasks)

Команда запускает React/Vite-клиент и Express/Socket.IO-сервер. Для изменения настроек скопируйте `.env.example` в `.env` в корне и перезапустите процессы.

| Переменная | Стандартное значение |
| --- | --- |
| `PORT` | `3001` |
| `CLIENT_ORIGIN` | `http://localhost:5173` |
| `VITE_SERVER_URL` | адрес страницы, порт `3001` |
| `MIN_PLAYERS` | `4` |
| `DISCUSSION_DURATION_MS` | `45000` |
| `VOTING_DURATION_MS` | `30000` |
| `KILL_COOLDOWN_MS` | `20000` |
| `SESSION_GRACE_MS` | `60000` |

Для быстрой проверки можно выставить `DISCUSSION_DURATION_MS=10000`, `VOTING_DURATION_MS=10000` и `KILL_COOLDOWN_MS=2500`. С `MIN_PLAYERS=2` удобно проверять лобби, роли и движение. Для полного игрового цикла оставьте четырёх игроков.

## Игра по Wi-Fi

1. В `.env` укажите `CLIENT_ORIGIN=*` и не задавайте `VITE_SERVER_URL`. Клиент сам найдёт сервер на том компьютере, с которого открыта игра.
2. Запустите `npm run dev` и узнайте IP компьютера, например `ipconfig getifaddr en0` на macOS.
3. Все игроки в той же сети открывают `http://<IP>:5173`.

`CLIENT_ORIGIN` принимает один адрес, несколько адресов через запятую или `*`.

## Локальный матч

1. В одной вкладке создайте комнату. Из трёх других вкладок войдите по коду с разными именами.
2. Выберите карту в лобби хоста. Все игроки могут гулять по карте и открывать её схему до старта. При смене карты нужно заново отметить готовность.
3. Нажмите **Ready** в гостевых вкладках, затем **Start** у хоста. В каждой вкладке появится её секретная роль. Члены экипажа получат по три задания.
4. Найдите подсвеченную панель на карте, нажмите **Use** и решите задачу. Командный прогресс обновится на всех экранах.
5. Обновите страницу в той же вкладке. Пока сессия активна, браузер вернёт игрока в его комнату с прежней ролью, позицией и прогрессом.
6. По окончании перезарядки предатель выбирает ближайшего мирного и нажимает **Kill**. Другой живой игрок нажимает **Report** рядом с телом.
7. Проголосуйте после обсуждения. После победы вернитесь в лобби, выберите другую карту и отметьте готовность для следующего матча.

### Управление

| Клавиши или кнопка | Действие |
| --- | --- |
| **WASD**, **стрелки** | Двигаться в лобби и матче |
| **Схема карты** | Посмотреть план, свою позицию и назначенные панели |
| **E**, **Use** | Открыть ближайшее назначенное задание |
| **Esc** | Закрыть задание или схему |
| **Kill**, **Report** | Убить выбранную цель или сообщить о теле рядом |
| **Голосовать**, **Skip** | Выбрать живого игрока или пропустить голосование |

## Карты и задания

- **Орбитальная станция** — восемь отсеков, от лаборатории и реактора до склада и навигации.
- **Глубинный маяк** — девять подводных залов, кольцевой маршрут, боковые проходы, рифовая лаборатория и термальный узел.

На каждой карте есть панели всех семи типов. В игре с четырьмя и более участниками все семь типов распределяются по экипажу.

| Задание | Что сделать |
| --- | --- |
| Спектрометр | Упорядочить сигналы по близости к опорной частоте |
| Эхо-сигнал | Запомнить сигнал и передать символы в обратном порядке |
| Стабилизатор | Набрать целевую сумму тремя регуляторами |
| Кольца наведения | Повернуть кольца в указанные направления |
| Маршрут дрона | Провести дрон по клеткам вокруг завалов |
| Шифр маяка | Расшифровать сигнальные символы по легенде |
| Карантин проб | Отобрать стабильные пробы по температурному порогу |

## Правила и ограничения

- В матче с 4–6 игроками один предатель, с 7–10 их два. Экипаж побеждает по заданиям или после исключения всех предателей. Предатели побеждают при численном равенстве с экипажем или перевесе.
- При равенстве голосов за лидирующие варианты или победе Skip никто не исключается.
- Комнаты хранятся в памяти процесса. Токен сессии хранится в браузерной вкладке. Обновление страницы и кратковременный обрыв связи сохраняют игрока. По окончании срока ожидания сервер удаляет отключившегося участника. Команда **Выйти** завершает сессию сразу.
- Игра рассчитана на управление с клавиатуры. В production build остаётся предупреждение о размере чанка Phaser.

## Проверки

```bash
npm run check
npm test
npm run build
git diff --check
git status
```

`npm test` проверяет правила, генерацию заданий, геометрию обеих карт и переподключение через Socket.IO. Игра и превью собираются в `client/dist`. Production-сервер запускается через `npm start` после сборки.

Проверено 29 автоматическими тестами. В четырёх вкладках Chrome пройдены все семь типов заданий, победа по заданиям, повторный матч на подводной карте и победа голосованием. Обновление страницы в лобби и матче сохранило игрока и его прогресс. Ошибок выполнения, необработанных Promise rejection и дублирующихся Socket.IO-обработчиков в проверенном сценарии не было.
